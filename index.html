SEO blueprint

Script → video

Turns your narration and a code block into an MP4: GitHub Actions narrates the voiceover script with Piper TTS and types the code block out in an animated editor (Revideo), then hands the finished file back here. Switch to Storyboard video for kinetic title / step / stat / CTA scenes.

Rendering needs a GitHub token — set it once in Advanced settings (top of the page). It only dispatches the ultimate-youtube-engine workflow on this repository.

One scene per line: TYPE | ON-SCREEN TEXT | ICON | NARRATION. TYPE is title, step, stat or cta. ICON is a Lucide name (van, battery-charging, sun, thermometer, home, wrench, zap, dollar-sign, mountain…).

Idle

API configuration

Your keys stay in this browser only (localStorage). The YouTube key and the direct Gemini engine talk straight to Google; the OmniRoute engine talks only to the gateway URL you supply. Nothing is relayed through any third-party server.

Keys saved locally

New here? Create a key in the Google Cloud console (enable YouTube Data API v3) and one in Google AI Studio (for Gemini). Restrict the YouTube key to your Pages domain for safety. For the OmniRoute engine, run your own gateway (local or hosted) and point it at the base URL above — learn more.

SEO blueprint

Script → video

Turns your narration and a code block into an MP4: GitHub Actions narrates the voiceover script with Piper TTS and types the code block out in an animated editor (Revideo), then hands the finished file back here.

Kept in this browser only (localStorage). It only needs to dispatch workflows on this repository — classic repo + workflow, or a fine-grained token with Actions: read and write.

Idle

SEO research runs entirely in your browser. The video render runs on GitHub Actions (ffmpeg + Piper + Revideo) — no server of your own.
